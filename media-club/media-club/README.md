# MEDIA CLUB — React (Vite)

    npm install
    npm run dev

- `src/styles.css`  your original CSS, unchanged
- `src/data.js`     team / portfolio / events / stories data
- `src/App.jsx`     all pages and components
- `src/stickman.js` the stickman photographer, ported as-is from the HTML

Not included (needs your backend / large separate features): login + dashboard, lightbox, likes/comments,
share-card generator, live WebGL background + 3D camera loader, notification fetching.
